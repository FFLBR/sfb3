# SafeBite — демонстрационный каталог

Каталог и сведения о составе, аллергенах, наличии и ценах демонстрационные, а не подтверждённые производителями. Информация не является гарантией безопасности: пользователь должен проверять фактическую этикетку.

В профиле доступны 14 категорий аллергенов: молоко, яйца, рыба, ракообразные, орехи, арахис, соя, содержащие глютен злаки, сельдерей, горчица, кунжут, сульфиты, люпин и моллюски. Непереносимость лактозы выбирается отдельно от аллергии на молочный белок; безлактозное молоко содержит молочный белок.

Демонстрационные профили 23 категорий описывают указанные в задании ингредиенты и возможные следы. При нескольких выбранных аллергенах прямое совпадение приоритетнее следов. Отсутствие совпадений означает только отсутствие отметки в учебных данных, а не установленную безопасность. Товары не скрываются по аллергенам: сначала отображаются товары без совпадений, затем возможные следы, затем прямые совпадения. Примеры без подтверждённой цены и магазина не добавляются в корзину.

Распознавание состава ищет распространённые маркеры и не является полной или медицинской проверкой этикетки.
